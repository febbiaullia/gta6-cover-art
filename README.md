# Cover Coast Studio

An offline web app that turns any photo and a caption into GTA-style cover
art: a multi-panel poster look with bold display lettering and a sunset or
neon colour grade, exported as a PNG to share.

- Load your own photos from your machine (they never leave it), or use the
  two built-in sample photos.
- Five layouts (Hero + Trio, Four Panels, Full Bleed, Triple Strip,
  Banner + Trio); crop and position each panel by dragging or with sliders.
- Five colour grades (Sunset, Neon, Palm, Vice, Noir) with grain and a
  vignette, plus a bold title and a script subtitle you can edit.
- Export in the common post sizes: 1080 x 1080, 1080 x 1350, 1920 x 1080.

Run it with any static server — for example, `python3 -m http.server` inside
`app/` — then open `app/index.html` in a desktop browser.
All lettering and art is original; the display fonts are Anton and Pacifico
under the SIL Open Font License (see `app/fonts/OFL.txt`). No game logos,
artwork or fonts are used anywhere.
